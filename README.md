# DevOps Sample Application

This is a simple HTML application created for the DevOps Internship Practical Task.

## Project Files

- index.html
- README.md
- .gitignore

## Setup

1. Clone the repository.

```bash
git clone <repository-url>
```

2. Open the project folder.

```bash
cd devops-sample-app
```

3. Open `index.html` in your web browser.

## Deployment

This application can be deployed using:

- Docker
- Kubernetes
- Nginx
